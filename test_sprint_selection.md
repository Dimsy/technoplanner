# Тестирование функции выбора спринта

## Функциональность, которая была реализована:

### 1. Выбор спринта
- Маркеры спринтов в верхней части календаря теперь кликабельны
- При клике на спринт:
  - Он выделяется синим цветом (#3498db)
  - В заголовке панели людей отображается номер выбранного спринта
  - В заголовке маркера спринта появляется иконка ✅
  - Происходит пересчет занятости людей только для задач в выбранном спринте

### 2. Расчет занятости по выбранному спринту
- В PeopleList.js добавлена функция `isTaskInSelectedSprint()`, которая проверяет, попадает ли задача в выбранный спринт
- Расчет количества задач и SP учитывает только задачи, которые полностью или частично находятся в выбранном спринте
- Для задач, которые частично в спринте, SP рассчитываются пропорционально части задачи в спринте

### 3. Сброс выбора спринта
- Добавлена кнопка "Показать все спринты" в панели людей (появляется только когда выбран спринт)
- При клике на кнопку снимается выделение со спринта
- Расчет занятости возвращается к исходному состоянию (учитываются все задачи)
- Также можно снять выделение, кликнув на уже выбранный спринт

### 4. Визуальные улучшения
- Маркеры спринтов имеют эффекты при наведении
- Выбранный спринт визуально выделен
- В заголовке панели людей отображается информация о выбранном спринте
- Цветовая схема сохраняет темную тему приложения

## Как проверить работу:

1. **Откройте приложение** по адресу: http://localhost:3001
2. **Кликните на любой маркер спринта** в верхней части календаря
3. **Проверьте изменения**:
   - Маркер спринта должен выделиться синим цветом
   - В заголовке панели людей должен появиться текст "Спринт X"
   - Проценты занятости людей должны пересчитаться
   - Кнопка "Показать все спринты" должна появиться в панели людей
4. **Кликните на кнопку "Показать все спринты"** или на уже выбранный спринт
5. **Проверьте сброс**:
   - Выделение с спринта должно сняться
   - Занятость должна вернуться к исходным значениям
   - Кнопка "Показать все спринты" должна исчезнуть

## Технические детали:

### Фильтрация задач по спринту:
```javascript
const isTaskInSelectedSprint = (taskX, taskWidth) => {
    if (selectedSprint === null) return true; // Все спринты
    
    const sprintStart = selectedSprint * 500; // Каждый спринт 500px
    const sprintEnd = (selectedSprint + 1) * 500;
    const taskEnd = taskX + taskWidth;
    
    // Задача попадает в спринт, если пересекается с ним
    return (taskX < sprintEnd && taskEnd > sprintStart);
};
```

### Расчет SP для частично входящих задач:
```javascript
// Вычисляем, какая часть задачи попадает в спринт
const overlapStart = Math.max(taskStart, sprintStart);
const overlapEnd = Math.min(taskEnd, sprintEnd);
const overlapWidth = Math.max(0, overlapEnd - overlapStart);

// Вычисляем долю SP, пропорциональную части задачи в спринте
const taskSP = task.sp || 0;
const taskTotalWidth = task.weight;
const overlapSP = taskSP * (overlapWidth / taskTotalWidth);
```

### Визуальное выделение выбранного спринта:
- Фон маркера: `backgroundColor: selectedSprint === i ? '#3498db' : '#1a252f'`
- Цвет текста: `color: selectedSprint === i ? '#ecf0f1' : '#3498db'`
- Иконка: `{selectedSprint === i ? '✅' : '📊'}`

## Ожидаемое поведение:

1. **Без выбранного спринта** (selectedSprint = null):
   - Все маркеры спринтов темные (#1a252f)
   - Занятость рассчитывается по всем задачам
   - Кнопка "Показать все спринты" скрыта

2. **С выбранным спринтом** (selectedSprint = число от 0 до 25):
   - Выбранный маркер спринта синий (#3498db)
   - Остальные маркеры темные
   - Занятость рассчитывается только для задач в выбранном спринте
   - Кнопка "Показать все спринты" видна

3. **При клике на уже выбранный спринт**:
   - Выделение снимается
   - Возвращается к состоянию "без выбранного спринта"
