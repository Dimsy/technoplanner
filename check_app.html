Тестирование функции выбора спринта

Тест 1: Клик на маркер спринта

Ожидаемый результат:

  • Маркер спринта должен выделиться синим цветом
  • В заголовке панели людей должен появиться текст "Спринт X"
  • Проценты занятости людей должны пересчитаться
  • Должна появиться кнопка "Показать все спринты"

Тест 2: Сброс выбора спринта

Ожидаемый результат:

  • При клике на кнопку "Показать все спринты" выделение должно сняться
  • Занятость должна вернуться к исходным значениям
  • Кнопка "Показать все спринты" должна исчезнуть
  • При клике на уже выбранный спринт выделение также должно сниматься

Тест 3: Расчет занятости по спринту

Ожидаемый результат:

  • При выборе спринта занятость должна рассчитываться только для задач в этом спринте
  • Для задач, которые частично в спринте, SP должны рассчитываться пропорционально
  • При сбросе выбора должны учитываться все задачи

Изменения в коде:

  • App.js: Добавлен state selectedSprint и функции для управления им
  • PeopleList.js: Добавлена фильтрация задач по выбранному спринту и кнопка сброса
  • CalendarBG.js: Маркеры спринтов стали кликабельными с визуальным выделением
⚠️ Важно:

Для работы приложения должен быть запущен backend сервер на порту 9000

Если backend не запущен, данные будут загружаться из начального состояния
