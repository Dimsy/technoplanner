### 4. Ключевые технические решения

#### Фильтрация задач:
```javascript
const isTaskInSelectedSprint = (taskX, taskWidth) => {
    if (selectedSprint === null) return true;
    const sprintStart = selectedSprint * 500;
    const sprintEnd = (selectedSprint + 1) * 500;
    const taskEnd = taskX + taskWidth;
    return (taskX < sprintEnd && taskEnd > sprintStart);
};
```

#### Пропорциональный расчет SP:

### 6. Логика работы

#### Состояния:
1. **Без выбранного спринта** (`selectedSprint = null`):
   - Все маркеры спринтов в обычном состоянии
   - Занятость рассчитывается по всем задачам
   - Кнопка "Показать все спринты" скрыта

2. **С выбранным спринтом** (`selectedSprint = число`):
   - Выбранный маркер выделен
   - Занятость рассчитывается только для задач в выбранном спринте
   - Кнопка "Показать все спринты" видна
   - В заголовке панели людей отображается номер спринта

#### Взаимодействие:
- Клик на маркер спринта → выделение + пересчет занятости
- Клик на кнопку "Показать все спринты" → сброс выделения + пересчет по всем задачам
- Клик на уже выбранный спринт → сброс выделения (альтернативный способ)
